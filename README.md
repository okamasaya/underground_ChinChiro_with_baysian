# 記録から見えない状態を推定する

**地下チンチロから潜在状態の推定と実社会への応用へ**

観測できる記録から、直接は見えない状態や指標をどこまで推定できるでしょうか。

本リポジトリでは、『カイジ』の地下チンチロを題材とした二項モデルのベイズ推定を出発点に、局面などの外的要因、観測間の依存関係、学習による状態変化を考慮した推論を検討します。理解度推定を一つの応用例として、不確かさの評価、予測の逐次監視、実社会での検証へ考察を広げています。

論文2編と、その計算・図版・保存データをまとめています。

## 扱う問い

- 出目をどの単位で記録すると、賽の使用戦略について何が分かるか。
- 通常賽を混ぜる場合や、局面に応じて使い分ける場合に、証拠の強さはどう変わるか。
- 事後確率、誤警報率、検知までの時間をどう区別して評価するか。
- 正誤の記録から推定する習得確率と、次回の正答予測は何が違うか。
- 不確かさやモデルのずれを評価し、学習支援・LLM品質管理・介入効果の検証へどうつなぐか。

## 主な結果

| 検討 | 仮定したモデルの下で得た結果 |
| --- | --- |
| 賽の戦略仮説の逐次判定 | 事前確率0.100・判定閾値0.990に対し、期間無制限の誤警報上界は1/891（約0.112%） |
| ベイズ知識追跡（Bayesian Knowledge Tracing; BKT）の有限標本の例 | 同じ8回答への対数尤度差が約4.432×10⁻⁵の2候補でも、習得確率は0.984と0.369に分かれる |
| 将来回答によるモデル比較 | 固定した2候補の正しい方向の尤度比が10倍に達する経験中央値は38問／8問、75%分位点は77問／95問 |
| 観測予測の逐次監視 | 履歴・出題条件を含む条件付き正答予測が正しいという帰無仮説の下で、期間無制限の誤警報保証を構成 |

これらは、明示した生成・観測モデルに基づく計算と模擬実験の結果です。現実の理解度や潜在習得状態の真偽を直接保証するものではありません。学生データによる有効性や介入の因果効果は、今後の実証課題として整理しています。

## PDFをビルドする

XeLaTeX、Noto Sans CJK JP、Noto Serif CJK JPを用います。両文書ともA4判です。ルートディレクトリで実行します。

```bash
latexmk -xelatex kaiji_ungr_456dice.tex
latexmk -xelatex kaiji_bayes_letter_20261105.tex
```

Letterは図の座標をTeX内に含めています。Full paperは同梱の`figures/`を参照するため、ディレクトリ構成を保ってください。

## 計算を確認する

Pythonの依存パッケージは`requirements.txt`にまとめています。保存済みの計算結果も同梱しているため、論文や図を見るために模擬実験を実行する必要はありません。

```bash
python -m pip install -r requirements.txt
```

実行する計算の範囲は[再現方法](docs/REPRODUCIBILITY.md)から選べます。将来BKT比較は各生成モデル20万系列・最大400問の計算です。

表示は原則として小数点以下3桁に丸め、計算値・厳密分数は丸めずに保存しています。到達率のMCSE（モンテカルロ標準誤差）はパーセントポイントで示します。

## 出典・制作について

物語の着想は福本伸行『賭博破戒録カイジ』の地下チンチロ編によります。分析上の観測系列は本稿で生成したもので、原作の対局記録を転記したものではありません。関連研究・国内の公開考察の書誌はFull paperに記載しています。

参考写真P01は提供画像、扉絵B01は画像生成AIによるイメージです。図版用フォントの元資料のライセンス表記は[fonts/OFL.txt](fonts/OFL.txt)、生成来歴は[fonts/provenance.json](fonts/provenance.json)に保持しています。
