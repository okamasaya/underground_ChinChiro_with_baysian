# 厳密なモデル計算と検知性能の再現

`chinchiro_model.py`は、通常賽216通り・456賽27通り、最大3投の停止規則、順位A/Bの勝敗を`Fraction`で求めます。局面別系列`CTX20-v1`は、4・8・12・16・20手番を事前に勝負どころと決めた20手番の例示です。被観測者seedは20261103、相手は20261108で、相手系列は勝負どころの敗戦を説明するために選んでいます。性能推定用の無作為標本としては扱いません。

`sequential_performance.py`は標準ライブラリのみで動作し、次を計算します。

- 事前確率0.100、事後確率閾値0.990に対応する累積BF閾値891。
- 到達済み状態を吸収する整数再帰による、誤警報・検知・未到達・打切り平均。
- 真の一定使用率を想定する判定器、90.000%に固定した判定器、共有未知率に一様事前分布を置いて積分する判定器の比較。
- 使用率の22設定（0〜1を0.050刻み、および0.225）、20・100・1000手番の感度。
- 勝者の役で倍率が決まる比較用配当族の係数、3種類の倍率例、通常賽同士の反対称性による期待純益0。
- 10手番の全1024系列との独立照合16条件、混合BFの多項式積分45条件、通常賽下の期待BF=1の9条件。

```bash
python analysis/chinchiro_model.py
python analysis/sequential_performance.py
python analysis/discussion_figures.py
```

`sequential_performance.json`と`frequency_sensitivity.csv`を生成します。内部再帰と境界比較は整数で、保存する通常の数値列は浮動小数点です。極小の未到達率については常用対数も保存し、検知率が1へ丸められても区別できるようにしています。`survival_log10`が`null`となるのは未到達重みが厳密に0のときです。

`discussion_figures.py`は日本語の追加図A16/A17を生成します。`figure_japanese.py`は既存図A01〜A15の表示ラベル、`display_precision.py`はそれらの小数点以下3桁・ROUND_HALF_UPを担当します。追加図も同じ数値表示関数を使います。回数軸は整数、確率・使用率・対数オッズは小数点以下3桁です。

`series_manifest.json`は、一定率の保存系列`CONST20-v1`と局面別系列`CTX20-v1`を区別します。同じseedでも生成設定が異なるため同じ出目列にはなりません。A14/A15のCSV・JSONには全履歴や厳密な役確率も残しています。

原作の配当・親番・精算規則の確定、実物の偏り、記録漏れ、局面の事後選択、人間が仮説を思い付く過程は、今回の単純モデルの保証から分けて検討します。


## BKTの追加検算と逐次監視

`bkt_sequential_validation.py` は2モデル×8接頭列の尤度・状態確率の32条件を、独立の隠れ状態列挙と照合する。将来10回答の全1024列で正規化と尤度比期待値を確認し、20万系列×2生成モデルの将来初到達を計算する。学習遷移と両フィルタを継続し、将来部分の尤度比を1から始める。

結果は `bkt_sequential_validation.json`、`bkt_future_first_passage.csv`、`bkt_future_first_passage.npz`。NPZの401は400問までの未到達。打切り平均を無制限期待時刻と混同しない。較正の一定予測例では分数・整数再帰を用い、モンテカルロ誤差を付けない。一様積分の賽判定器は正項ベータ展開で境界の両側200条件を独立照合する。

`bkt_validation_figures.py` がA22/A23を生成する。図用フォントは `figure_fonts.py` でTrueTypeを登録する。本文で用いる全図のPDFを直接書き出し、Type 3の除去とUnicode抽出を確認した。


## 2026年11月6日改訂時の再現条件の補足

将来BKT比較は、過去8回答後の丸め前の `q9` から各候補のフィルタを再開する。候補ごとの `G,S,T` を将来も固定し、候補間で同じ値にはそろえない。潜在状態を別途標本化せず、真としたモデルの履歴条件付き正答予測から二値結果を生成し、両フィルタへ同じ結果を入力する。

NumPy PCG64、seed `2026110302` の `SeedSequence.spawn(2)` で生成モデル別に分岐する。経験分位点は `method="inverted_cdf"`。到達率は%、そのMCSEは `100*sqrt(p_hat*(1-p_hat)/200000)` パーセントポイントで表示する。打切り平均のMCSEの単位は問題数である。

今回の本文改訂では計算コード・図版・生データを変更せず、保存済み結果を照合した。20万系列×2生成モデルの模擬実験は再実行していない。
